Frontier Model Behavior: Claude Opus 4.7/5.5 & Claude Design (Threads 2 & 3)

Why Models Converge on Slop (& How to Fix It)

  • Anthropic Skills Study: Names "distributional convergence" (Inter, purple gradients, 3-card grids). Models have far higher capability than default prompts unlock.
  • Contra Labs (600 Blind Designer Comparisons): Top failure modes were missing imagery (33 write-ups) ("each page had to draw its own with code"), text-heavy sections (32), and faint/low-contrast text (26).
  • Specific Bans Beat Vague Prompts: Saying "avoid a generic AI look" just swaps one default for another. Naming concrete bans (no `01/02/03` rails, no italic accent words, no pill badges above H1) plus 3–5 reference screenshots + `DESIGN.md` transforms output quality.

7 Automatic Motion Checks (Linear §1 §6 & docs/15_MOTION_ANIMATION_PLAN.md)

#Check NameVerification Rule
1Compositor-Only Static ScanFail if `@keyframes` or `transition` animates layout properties (`top`, `left`, `width`, `height`, `margin`). Only `transform` and `opacity` allowed.
2Reduced Motion EmulationPlaywright emulates `prefers-reduced-motion: reduce`; all non-essential scroll/loop animations must stop or collapse to instant opacity fade.
3Progressive Enhancement Guard`animation-timeline: view()` and cross-document View Transitions must sit inside `@supports` with clean static fallback.
4Runtime Trace (Playwright + CDP)Zero Layout/Paint thrashing during scroll; zero long animation frames `> 50ms`; lab INP `<= 200ms`.
5Motion Token AdherenceEvery duration (3 steps) and easing curve (2–3 curves) comes from the declared S4 motion token set.
6Initial Bundle Weight GateThree.js / WebGL / Rive / Lottie bundles are lazy-loaded via `import()` on intersection/interaction, never in initial blocking bundle.
7Library & CDN HygieneGSAP loaded from pinned npm package (`gsap`), zero private tokens, zero unpinned third-party script tags (replaces `render.ts:3292` `unpkg.com` HTMX tag).
