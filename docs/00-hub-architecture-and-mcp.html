DesignProof: The Design Eye & Proof Loop for Coding Agents

Coding agents (Cursor, Claude Code, Grok Build, Windsurf) write code blind to the rendered DOM. DesignProof (designproof.site) is the MCP plugin + CLI + skill suite that captures the live rendered page in headless Chromium, names 13 Genericness Tells and 8 Consistency Drifts, takes plain-English or voice direction, synthesizes WCAG-verified CSS/token patches, and proves zero regressions in a disposable git worktree before a human approves.

Visual Product Walkthrough (Actual Rendered Captures from docs/media/)

01 · Capture

Playwright DOM Probe

Captures 1440×1100 & 390×844 viewports, computed styles, bounding boxes, and hover state transitions.

02 · Diagnose

Name Tells & Drift

Pins numbered Terracotta badges (13 Genericness Tells) & Ochre badges (8 Consistency Drifts) to selectors.

03 · Art Direct

Voice & Preset Direction

Translates plain-English briefs into 7 concrete typography, palette, spacing, and layout structures.

04 · Repair

Contrast-Safe Diff

Emits WCAG AA verified CSS variables + Tailwind overrides. Never mutates user files without approval.

05 · Prove

Before / After Seam

Applies patch in disposable git worktree, recaptures 3 viewports, and verifies newTells === 0.

5-Beat Ashish Demo Script & Senior Critic Voice Contract (from USER_STORY.md & CONTRIBUTIONS.md)

Senior Design Critic Copy Rules

  • Max 3 sentences per TellCard: (1) Measured DOM fact with selector/numbers, (2) Why it reads as a generic template or drift, (3) Concrete token/CSS fix.
  • Zero hedging: Never write "Consider...", "You might want to...", or "Perhaps...".
  • Zero emojis in product chrome: Orbs, sparkles, and celebratory confetti are banned (`NoEmojiChromeTell` dogfooded on `apps/web`).
  • Attribution Hygiene (CONTRIBUTIONS.md): Every commit uses Ashish <ashish@bimlabz.com>; zero Co-authored-by trailers.

5-Beat Demo Rehearsal Flow

  1. Beat 1 (Paste URL): Capture http://localhost:3001 (`fixtures/generic-app`) or click Load sample report offline fallback (`fixtures/reports/tell-report.json`).
  2. Beat 2 (Inspect Findings): Show Genericness Score (`78/100`), click Terracotta pin `#1` (`GradientCrutchTell` / `FontDefaultTell`), toggle `/brutalist` route to prove Gemini marks intentional choices `intentional` (Forest badge).
  3. Beat 3 (Direct): Click Editorial Serif or speak "Make it feel like an architectural monograph on warm paper".
  4. Beat 4 (Seam): Drag `BeforeAfterSeam` (`2px` Terracotta `#D4714A` rule, `40px` brass handle, keyboard arrows `2%`, `Shift+Arrow` `10%`).
  5. Beat 5 (Prove): Run `tell_proof_verify` in Cursor MCP (`78 → 14`, `0` new tells across `375px / 768px / 1440px`).
