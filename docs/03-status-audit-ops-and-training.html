Hybrid Deployment Architecture (Vercel + Vultr/Render + Neon)

Because Playwright Chromium (`~350MB`) exceeds Vercel's serverless bundle size and timeout limits, DesignProof uses a split hybrid topology when deployed to the cloud, while running 100% locally in Cursor/CLI.
