Disposable Git Worktree Verification (tell_proof_verify) & 3-Round Critique Loop

Worktree Proof Protocol (proof-verify.ts)

  1. Creates disposable worktree via git worktree add --detach in os.tmpdir().
  2. Applies candidate CSS/Tailwind patch inside the isolated worktree only.
  3. Captures 375px / 768px / 1440px × light / dark matrix via tell_capture_matrix.
  4. Re-runs all 21 detectors and computes ProofVerificationReport:
    • verified = (afterScore < beforeScore) && (newTells.length === 0) && (wcagFailures === 0)
  5. Always cleans up worktree in finally (`tell_proof_revert`).

3-Round Screenshot Critique Loop (critique.ts)

  • Round 1 (Macro Layout & Frame): Checks fold cutoffs (`TitleOnFoldTell`), mobile overflow (`MobileFirstScreenTell`), and gutter symmetry (`FrameGutterTell`).
  • Round 2 (Typography & Contrast): Audits display/body font pairing, line measure (`<= 75ch`), and WCAG AA contrast ratios across all text nodes.
  • Round 3 (Surface & Rhythm): Eliminates residual card monotony, blank stretches (`> 260px`), and dead hover states. Converges early when `genericnessScore <= 20`.
